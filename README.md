# Creative Income Command Center

A standalone, interactive strategic dashboard for building a realistic path from **₹25,000/month toward ₹50,000, ₹1,00,000, ₹2,00,000, and ₹5,00,000+/month** at the intersection of technology, visual creativity, AI, international client work, software, and original IP.

The strategy is tailored for an India-based technical professional who wants to move toward creative and owned income **without making education, face-based content, personal celebrity, or virality the business model**.

## Open the command center

Open [`index.html`](./index.html) in any modern browser. It requires:

- no installation;
- no package manager;
- no build step;
- no backend;
- no external JavaScript or CSS dependencies.

For consistent browser behavior, it can also be served as a static file:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Strategic recommendation

The researched strategy is a sequence rather than a collection of unrelated side hustles:

1. **Primary cash engine — faceless product-launch creative systems:** create product films, UI-motion launch loops, channel-native cutdowns, visual variants, and repeatable production workflows for B2B SaaS/AI companies.
2. **Secondary hedge — creative workflow automation:** automate brief intake, approvals, asset/version management, localization, and delivery for creative or marketing teams.
3. **Long-term owned asset — narrow workflow plugin or micro-SaaS:** build only after repeated paid pain and real pre-commitment from design partners.
4. **Capped creative option — original comedy character IP:** use original animation as creative R&D and an asymmetric option, not as a base-case income forecast.
5. **Runway protection — retain employment initially:** test aligned creative-tech and AI workflow roles if service evidence remains weak or a materially better role improves runway.

The command center clearly labels market facts, assumptions, estimates, conditional projections, and uncertainties. It does not promise income.

## Interactive features

- Current-income dashboard and income ladder
- Clickable strategy explorer
- Sortable and filterable 25-path opportunity matrix
- Full 18-criterion weighted scoring for every opportunity
- Creative niche explorer across art, comedy, animation, design, AI, software, games, products, services, and IP
- Day 1–30 mission board with saved checkboxes
- Interactive 12-month roadmap and decision gates
- Revenue calculator for clients, projects, products, subscriptions, expenses, platform fees, contractors, and a planning reserve
- Local client-acquisition tracker with stage updates, revenue summary, and CSV export
- Skill, portfolio, and weekly KPI trackers
- Conservative, base, and aggressive financial scenarios
- Interactive decision tree
- International pricing guidance
- Capital-release ladder and lean tool stack
- Risk, quit, job-switch, hire, product, and pivot rules
- Source ledger with current official/report links
- A persistent “Do this today” action bar

All tracker and mission data is stored locally in the browser with `localStorage`. Nothing is transmitted. Browser data can be lost if site data is cleared, so the prospect tracker includes CSV export.

## Research basis

The evidence snapshot is dated **14 September 2026** and prioritizes official platform, government, pricing, policy, job-market, and first-party report sources. The dashboard includes the complete claim-to-source ledger.

Important evidence categories include:

- IAB/PwC digital advertising and video-market reports;
- YunoJuno contractor-rate benchmarks;

- YouTube and Meta originality/monetization policies;

- Gumroad, Patreon, itch.io, Adobe Stock, Shopify, and plugin/SaaS economics;

## Key planning boundaries

- Pricing, conversion rates, time-to-income, costs, and success probabilities are estimates—not guarantees.
- The default ₹90/US$ exchange rate is a planning assumption and should be replaced with actual settlement rates.
- Revenue targets refer to gross business revenue sustained for three consecutive months unless stated otherwise.
- The calculator’s “tax reserve” is a cash-planning input, not a tax computation or professional tax advice.
- US/UK contractor benchmarks do not represent guaranteed India-based beginner rates.
- AI commercial-use permission does not guarantee copyrightability, exclusivity, non-infringement, or freedom from likeness/trademark risk.
- Payment eligibility, platform rules, pricing, GST/export treatment, and income-tax treatment must be rechecked for the user’s actual facts.

## Design and privacy

The interface is responsive for laptop and mobile, keyboard accessible in its core controls, printable, and intentionally dependency-free. It uses system fonts and inline CSS/JavaScript so the single HTML file remains portable and works offline.

This project has no analytics, cookies, network calls, accounts, or backend persistence.
